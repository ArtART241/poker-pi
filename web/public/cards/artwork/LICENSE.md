# Artwork deck

"Vector Playing Cards" by Byron Knoll, released into the public domain
(optionally WTFPL where public domain is not recognized).
Source: https://github.com/notpeter/Vector-Playing-Cards (folder `cards-svg`), originally
https://code.google.com/p/vector-playing-cards/

The files here were optimized with `svgo --precision 1` (smaller, visually identical).

To remove this deck: delete this folder and the `artwork` entry in `web/src/lib/settings.svelte.js`
(`DECKS`) and its branch in `web/src/lib/Card.svelte`.
